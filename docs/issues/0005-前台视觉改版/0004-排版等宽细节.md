# Issue-0004：排版等宽细节（Maple Mono 应用到细节处）

## Parent

PRD：`../../prd/0004-前台视觉改版.md`

## What to build

强化 Maple Mono 等宽字体在界面细节处的使用，建立「正文无衬线系统栈 + 细节等宽」的双层字体节奏。落点：导航项、分区序号/计数、时间戳、标签 pill。不改正文字体。

## Acceptance criteria

- [ ] `widgets/Header/HeaderNav`：导航项加 `font-mono` + 适度字间距（如 `tracking-wide`）
- [ ] 首页/列表页的分区计数（如"最新文章"旁的篇数、"12 篇"等）：`font-mono` + `text-muted-foreground`
- [ ] `features/posts/ui/PostCard` 的相对时间戳：`font-mono`
- [ ] 标签 pill（PostCard 的 tag、各处 badge）：`font-mono` + `tracking-tight`
- [ ] 保持正文、标题仍用无衬线系统栈，不动 `body` 字体定义
- [ ] 三套主题下等宽细节视觉一致（字体不随主题变，只配色随）
- [ ] `make web-typecheck && make web-lint` 全绿

## Blocked by

Issue-0001（主题 token 系统）—— 虽排版改动不直接依赖配色，但统一在三套主题就绪后验收，避免配色未定时反复调整。可与 Issue-0002/0003 并行。

## 实现指引

- Maple Mono 已通过 `--font-mono` 注册（`@fontsource/maple-mono` 400/700），`font-mono` 工具类直接可用，无需新引入字体。
- 注意 CJK 字符在等宽字体下的回退：Maple Mono 是英文字体，中文会回退到系统栈，标签/计数多为英文/数字，影响小；导航项含中文时确认排版仍协调。
- 这是纯样式细节，改动分散但单点都很小，建议一次性扫完所有落点。

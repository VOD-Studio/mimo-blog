# Issue-0003：动效随主题适配（glow / SpotlightCard / ParticleField）

## Parent

PRD：`../../prd/0004-前台视觉改版.md`

## What to build

把现有动效组件（`ParticleField`、`SpotlightCard`、glow 辉光、`CustomCursor`、LandingHero 渐变 blob 等）的颜色从硬编码/`--neon-*` 切换为引用语义 token（`--primary` / `--accent`），使其在三套主题下自动适配。即：切到璃月→辉光是金，切到绝区零→辉光是荧光黄绿，切到中性→辉光克制。

## Acceptance criteria

- [ ] 审查 `shared/ui/particle-field.tsx`、`shared/vendor/react-bits/SpotlightCard`、`shared/ui/cursor.tsx`、`widgets/LandingHero/` 等含动效颜色的组件，把硬编码色值（含 `--neon-*`）改为引用 `--color-primary` / `--color-accent` 或派生变量
- [ ] 三套主题下逐个检查动效组件视觉协调（不出现霓虹紫与璃月金冲突、绝区零荧光色过曝等）
- [ ] 中性主题下辉光强度自动降低（因中性强调色为灰，glow 应弱化为接近无色，而非死灰块）——必要时引入 `--glow-intensity` 变量按主题调节
- [ ] `prefers-reduced-motion` 下动效仍正确降级（现有行为不破坏）
- [ ] 手动验证：在三套主题间切换，Hero 的 blob、ParticleField、SpotlightCard hover 聚光、CustomCursor 颜色都跟随主题
- [ ] `make web-typecheck && make web-lint` 全绿

## Blocked by

Issue-0001（主题 token 系统）—— 动效颜色改引用语义 token，依赖 token 已定义。

## 实现指引

- 主要工作是"去硬编码、转 token 引用"，不改动动效逻辑本身。
- `--neon-*` 变量保留定义，但组件层面尽量改用 `--primary`/`--accent`，让一套代码服务三套主题。
- 中性主题辉光弱化是关键细节：中性强调色无色相，强 glow 会显得脏。可用 `color-mix()` 把 glow 透明度降低，或按风格类调 `--glow-intensity`。

# Issue-0005：首页 Hero 场景（取景器大字）

## Parent

PRD：`../../prd/0004-前台视觉改版.md`

## What to build

重做首页首屏，把现有 `LandingHero`（粒子场 + 渐变 blob + 终端卡）替换为**取景器风格的大字 Hero**：四角取景器边框装饰 + 流体响应式大字品牌名（`clamp()` + 容器查询单位 `cqw`）+ 状态脉冲。这是滚动叙事首页的第一屏，必须 SSR 直出。

本 issue 只做 Hero 单场景，不涉及滚动联动（后续 issue）。建立首页场景化的组件骨架。

## Acceptance criteria

- [ ] 新增 Scene 组件骨架（如 `widgets/HomeScenes/HeroScene.tsx` 或重构 `LandingHero`），作为首页多场景架构的第一个场景
- [ ] Hero 含取景器风格四角边框装饰（纯 CSS，四个角的 L 形线条）
- [ ] 品牌名/站点名用流体字号：`clamp()` + `cqw`（容器查询单位）实现随容器宽度缩放的大字
- [ ] 含状态脉冲动画（如"在线"呼吸点），`prefers-reduced-motion` 时降级为静态
- [ ] Hero 必须 SSR 直出（首屏不依赖客户端 JS 才显示），loader 沿用现有数据预取
- [ ] 三套主题下 Hero 视觉协调（强调色跟随主题 token）
- [ ] 改 `routes/index.tsx`：用新 HeroScene 替换 `LandingHero`（其余分区暂保留，后续 issue 处理）
- [ ] `make web-typecheck && make web-lint` 全绿

## Blocked by

Issue-0001（主题 token 系统）—— Hero 强调色引用语义 token。

## 实现指引

- 容器查询字号：给 Hero 容器设 `container-type: inline-size`，标题用 `font-size: clamp(下限, Ncqw, 上限)`。
- 取景器四角用伪元素或绝对定位的 4 个 div 画 L 形 border。
- SSR 注意：Hero 内容（站点名等）应来自 settings（站点设置），loader 已有 settings 预取可复用。
- 此 issue 不引入滚动驱动库（Lenis/GSAP），Hero 入场动画用现有纯 CSS（参考 styles.css 的 `blur-in`/`clip-reveal`）。

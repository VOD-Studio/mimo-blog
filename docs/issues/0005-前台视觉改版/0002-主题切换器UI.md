# Issue-0002：主题切换器 UI（风格 + 明暗）

## Parent

PRD：`../../prd/0004-前台视觉改版.md`

## What to build

在现有 `widgets/ThemeToggle/` 基础上，把切换器从「仅明暗」升级为「风格（原神·璃月 / 绝区零 / 中性）+ 明暗」两个独立控件。风格选择器选定 palette，明暗仍由现有切换器管理。切换风格复用 `animateThemeRipple` 圆形扩散 View Transition。

## Acceptance criteria

- [ ] 新增风格选择器组件（位置在 `widgets/ThemeToggle/` 下，或在 `widgets/` 新建），支持三选一：原神·璃月 / 绝区零 / 中性
- [ ] 风格选择器读写 Issue-0001 的 `palette` cookie，并在 `<html>` 上增删 `theme-*` 类
- [ ] 切换风格时调用 `animateThemeRipple`（复用 `shared/ui/theme-transition.tsx`）触发圆形扩散，不触发页面导航 VT
- [ ] 明暗切换器（现有 7 个 variants）保持不变，与风格选择器并存且互不干扰
- [ ] 切换器在 Header 的 `HeaderActions` 中合理放置，移动端（`HeaderMobile` Sheet）也能访问
- [ ] 切换后风格 + 明暗状态都被持久化，刷新保持
- [ ] 集成测试：选「绝区零」→ `<html>` 有 `theme-zzz` + cookie 写入；再切暗色 → `theme-zzz dark` 两个类共存
- [ ] `make web-typecheck && make web-lint && make web-test` 全绿

## Blocked by

Issue-0001（主题 token 系统）—— 切换器依赖 palette cookie 与风格类机制。

## 实现指引

- 风格选择器的视觉形态推荐用现有 variants 里的一种（如 `segmented-toggle` 或 `pie-menu-toggle`）适配，或新建一个简洁的三选一控件。三个选项可配一个小色块预览（金棕 / 荧光黄绿 / 灰）增强辨识。
- 不要把风格塞进 next-themes 的 theme 值——风格与明暗是两个独立 cookie + 两个独立控件。
- 圆形扩散复用 `use-theme-switcher.ts` 的模式：拿点击坐标 → `animateThemeRipple`。
